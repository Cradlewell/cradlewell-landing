Namma Route

A public-transport-first trip planner for Bengaluru. Keys are already built in — change them here only if you need to. Overrides are stored in this browser's localStorage and sent nowhere except Google.

APIs this app needs

  1. Maps JavaScript API — required, draws the map.
  2. Routes API — required, does all the routing. (The old Directions API is Legacy and can no longer be enabled on new projects.)
  3. Places API (New) — optional, powers the search dropdown. Without it you can still type full place names.

Enable them in Cloud Console → APIs & Services → Library. Billing must be on, though a monthly free allowance covers personal use.
